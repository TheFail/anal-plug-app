# Anal Plug App

Private, local-only Android diary for tracking anal plug use.

## Tech
- Kotlin
- Jetpack Compose
- Room (local SQLite)
- Material 3 (dark-first theme)
- Coil (photos)

## Features
- Plug catalog with photos, tags, material/shape/size, vibration & remote-app flags
- Full add/edit form with system photo picker (images copied to private storage)
- Plug detail screen with wear history
- Profile (name, age, sex) — local only
- Bottom navigation: Dashboard · Plugs · History · Profile

## Structure
All source is under `app/src/main/java/com/analplug/app/`.

## Privacy
Everything stays on the device. No cloud, no network required for core functionality.

## Status
Work in progress. Dashboard and History screens are still scaffolds. Session logging and calendar view to be added.
